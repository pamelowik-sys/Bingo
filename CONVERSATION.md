## О чём договорились

### Идея проекта
Создать Telegram бота, который зарабатывает на реферальных комиссиях
с каждого обмена токенов (свапа) в TON блокчейне.

### Выбранный подход
Интеграция с **STON.fi Omniston** — агрегатором ликвидности на TON.
- Объём STON.fi: $3.7 млрд всего, 27 млн свапов, 5.3 млн пользователей
- Каждый свап через бота несёт наш `referrer_address`
- STON.fi автоматически зачисляет **0.3%** на наш кошелёк в той же транзакции
- Не нужно держать деньги пользователей — пользователи свапают, мы зарабатываем

### Почему TON/STON.fi (а не Ethereum, Solana и т.д.)
- 900 млн пользователей Telegram — готовая аудитория
- Комиссии < $0.01 (делает микросвапы выгодными)
- Официальный Referral Fee API у STON.fi
- Python SDK + WebSocket — быстро интегрируется

| Команда | Что делает |
|---------|-----------|
| `/start` | Приветствие и быстрый старт |
| `/help` | Список команд |
| `/tokens` | Поддерживаемые токены |
| `/balance` | Баланс кошелька бота |

### Технический стек

```
Python 3.10+
python-telegram-bot 21.5   — Telegram Bot API
tonsdk 1.0.13              — TON кошелёк и транзакции
websockets 11-12           — WebSocket для Omniston API
aiohttp 3.9                — HTTP запросы к Toncenter
python-dotenv              — Загрузка .env
```

### Архитектура заработка

```
Пользователь пишет /swap 1 TON USDT
        │
        ▼
telegram_bot.py → omniston.py
        │           │
        │           └── WebSocket → wss://omni-ws.ston.fi
        │               Параметры: referrer_address=НАШ_КОШЕЛЁК
        │                          referrer_fee_bps=30 (0.3%)
        │
        ▼
Получаем лучший курс от всех DEX на TON
(STON.fi v1/v2, DeDust, Tonco, Escrow)
        │
        ▼
ton_wallet.py → подписываем транзакцию → Toncenter API → TON сеть
        │
        ▼
Пользователь получил USDT
STON.fi автоматически зачислил 0.3% на наш кошелёк
```

## Что нужно для запуска

1. **Telegram Bot Token** → @BotFather → `/newbot`
2. **TON адрес** (EQ...) → @wallet в Telegram
3. **Toncenter API ключ** → @toncenter в Telegram
4. Пополнить кошелёк бота минимум **0.05 TON** для газа

## Математика заработка

```
Комиссия = Сумма свапа × 0.30%

100 свапов/день × $50 средний свап = $15/день = $450/месяц
1000 свапов/день × $50             = $150/день = $4500/месяц
10000 свапов/день × $50            = $1500/день = $45000/месяц
```
